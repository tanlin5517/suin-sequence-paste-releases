# 顺序粘贴：公开安装与更新

[下载最新正式版](https://github.com/tanlin5517/suin-sequence-paste-releases/releases/latest)

安装版 EXE、免安装 EXE 和完整 ZIP 均可直接下载，无需 GitHub 账号、令牌或 GitHub CLI。Windows 10/11 x64；安装后使用软件内更新入口即可检查新版。

从 v3.2.0 起默认使用此公开更新渠道。v3.1.x 及更早版本若无法访问原私有渠道，请下载新版 EXE，在原目录安装一次；配对、偏好和队列保留，之后更新无需授权。

此仓库用于公开分发通用安装包及更新包，不包含设备身份、配对密钥、剪贴板内容、队列或私人设置。使用包包含必要运行脚本和 AutoHotkey 原许可证；完整开发源码仓库仍单独保持私有。

客户端核对 SHA256、文件清单及版本，更新前备份程序，失败会回退。更新需要网络，安装目录需要当前用户可写。

版本标签中的 `packages/` 来自维护仓库经过验证的构建，公开发行工作流再次核对 SHA256 后发布 Release。

v3.3.1 新增已配对电脑间的文件剪贴板同步：任意文件类型、多文件及文件夹，默认单个 100 MB / 每批 500 MB，可设置发送、接收、文件夹和自动准备开关。完整接收并核对大小及 SHA256 后才准备粘贴；支持进度、取消、手动重新发送和闲置缓存清理。两台均需新版，首次连接文件功能若失败，请在各自“局域网连接设置”允许文件连接。建议关闭无界鼠标的剪贴板/文件共享，保留鼠标键盘共享。

本版只同步本机已经保存的实体文件，每台同时处理一批；不支持虚拟附件、链接/联接点、直接 UNC 路径、断点续传或重启历史恢复。文件内容和目录结构保留；跨电脑剪切按复制处理，不删除源文件，也不自动运行文件。
